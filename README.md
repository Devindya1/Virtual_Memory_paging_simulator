Virtual Memory Paging Simulator

This project is a Virtual Memory Paging Simulator developed using C and JavaScript. It demonstrates fundamental Operating System memory management concepts in a simplified and interactive way.

🚀 Features
- Console-based simulator implemented in C
- Web-based simulation interface using JavaScript
- Demonstrates key OS concepts:
- Paging and page tables
- Frame allocation
- Page fault handling
- Logical-to-physical address translation
- Displays clear results including:
- Page hits and misses
- Physical address mapping outputs
  
📚 Purpose
This project is designed for educational use to help understand how virtual memory systems operate internally, including how processes access memory and how the OS manages translation between logical and physical memory.
